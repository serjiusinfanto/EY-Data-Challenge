# Urban Heat Island Prediction - EY Data Challenge IC25

## Overview
This repository contains the codebase and data for the EY Urban Heat Island (UHI) Data Challenge, part of the University of Maryland Information Challenge 2025 (IC25). The objective of this project is to develop a machine learning model to predict Urban Heat Island (UHI) index values based on Sentinel-2 satellite imagery data.

## Project Description
The Urban Heat Island (UHI) effect results in increased temperatures in urban environments compared to surrounding rural areas. This challenge aims to create an AI-driven model that predicts UHI hotspots across Montgomery County, Maryland, using near-surface air temperature data and satellite images.

### Goals:
- Develop a machine learning model to predict UHI index values using Sentinel-2 data.
- Identify key drivers contributing to urban heating.
- Provide insights for urban planners to mitigate the UHI effect.
- Ensure model generalizability by avoiding spatial autocorrelation issues.

## Data
The project leverages two core datasets:
1. **Training Data (`Training_Data_IC25.csv`)**: Contains UHI index values at 34,502 locations along with latitude and longitude.
2. **Satellite Data (`Sentinel2_IC25_median.ipynb`)**: Preprocessed Sentinel-2 multispectral satellite imagery providing features for prediction.
3. **Submission Data (`Submission_Template_IC25.csv`)**: A dataset for validating model predictions.
4. **Predicted Data (`Predicted_Data_IC25.csv`)**: A CSV file containing UHI index predictions generated by the trained model.

## Usage
1. **Run the Satellite Data Processing Notebook** (`Sentinel2_IC25_median.ipynb`):
   - Prepares Sentinel-2 satellite data for model training.
2. **Run the Benchmark Model Notebook** (`Benchmark_IC25.ipynb`):
   - Loads the training data.
   - Preprocesses features.
   - Trains a regression model.
   - Evaluates model performance using R-squared score.
3. **Generate Predictions**:
   - Use the trained model to predict UHI index values for the validation dataset (`Submission_Template_IC25.csv`).
   - Save predictions in `Predicted_Data_IC25.csv`.
4. **Submit Predictions**:
   - Upload `Predicted_Data_IC25.csv` to the EY Data Challenge platform ([challenge.ey.com](https://challenge.ey.com)).
   - The leaderboard will evaluate performance based on the R-squared score.

## Rules and Constraints
- **No external datasets**: Only Sentinel-2 data is allowed.
- **No use of latitude and longitude**: Including these as features leads to spatial autocorrelation and is prohibited.
- **Limited submissions**: A maximum of 5 submissions per day.

## Evaluation
Model performance is assessed based on:
- **R-squared Score**: Measures how well predictions match the true UHI index values.
- **Interpretability**: Importance of satellite features in driving UHI hotspots.
- **Scalability**: Potential of the model for other urban environments.

## Business Impact
- Helps urban planners identify UHI hotspots.
- Provides insights into how vegetation, water bodies, and urban density impact UHI.
- Can influence urban planning decisions to mitigate extreme heat effects.
